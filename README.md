# 🏓 Tischtennis-Kaiserturnier

Eine einfache App für ein Kaiserturnier im Tischtennis-Doppel: 24 Personen, 12 Doppel, 6 Tische.

**Direkt im Browser öffnen:** https://jjwatt20896.github.io/tischtennis-kaiserturnier/

Oder `index.html` herunterladen und per Doppelklick öffnen – funktioniert auch offline.

## Funktionen

- Personen per Schnelleingabe, eingefügter Liste oder CSV/TXT-Datei (`Spitzname;Level`) eintragen, mit Prüfung auf doppelte Namen und ungültige Angaben
- Beispielliste mit 24 erfundenen Spitznamen
- Doppel auslosen: möglichst je eine Person aus Level 1 und Level 2, eigene Teamnamen
- 1–30 Runden à 4 Minuten mit großer Uhr und Tonsignalen (Start, Halbzeit, Ticken, Schluss)
- Tisch 1 ist der Kaisertisch: Sieger steigen einen Tisch auf, Verlierer einen ab
- Siegtabelle mit gleichem Rang bei Gleichstand

## Datenschutz

Nur erfundene Spitznamen verwenden. Alle Eingaben bleiben lokal im Browser, nichts wird übertragen oder dauerhaft gespeichert. Neuladen löscht den Stand. Beim Online-Aufruf über GitHub Pages verarbeitet GitHub technische Zugriffsdaten (z. B. IP-Adresse) beim Laden der Seite.
